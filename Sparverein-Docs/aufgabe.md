# Sparverein
### Originalthema von der LAP

## Einleitung
Der Vereinskassier in Ihrem Hobbyverein hat sein Amt abgegeben, und Sie sollen in seine Fußstapfen treten. Um die Buchführung der Bargeldkasse einfacher zu
machen, wollen Sie sich ein Programm schreiben, welches Ein- und Auszahlungen aufzeichnet. Zusätzlich soll es, um die Finanzen des Vereins besser steuern zu können, einen Statistikabschnitt geben.

## Detailbeschreibung
- [x] Das Programm soll Ein- und Auszahlungen erfassen (zusammen auch als **„Zahlung"** bezeichnet). 
- [x] Jede Zahlung speichert den ein- bzw. ausgezahlten Betrag, das Datum, eine kurze (maximal 50 Zeichen) Beschreibung, 
- [x] sowie welches Vereinsmitglied die Zahlung getätigt hat.
- [x] Zahlungen dürfen dabei nur für das aktuelle oder vergangene Zeitpunkte eingetragen werden. 
- [x] Zahlungen sollen jederzeit nachträglich bearbeitet (Betrag, Datum, Beschreibung, Vereinsmitglied) und gelöscht werden können. 
- [x] Für ein **Vereinsmitglied** müssen Vor- und Nachname erhoben werden, 
- [x] außerdem kann optional ein Bild hochgeladen werden. 
- [x] Vereinsmitglieder sollen außerdem in einer einfachen Liste angezeigt werden können. 
- [x] Außerdem sollen Vereinsmitglieder als inaktiv markiert werden können. Für sie dürfen dann keine neuen Zahlungen mehr eingetragen werden.

- [x] Auf der Startseite sollen alle Zahlungen chronologisch absteigend angezeigt werden, 
- [x] Für jede Zahlung sollen Betrag, Zeitpunkt, Name der Person (inklusive Bild, falls verfügbar), und Beschreibung angezeigt werden. 
- [x] Außerdem soll es eine Such- und Filterfunktion geben, mit der die angezeigten Zahlungen eingeschränkt werden können. 
- [x] Die Suchfunktion durchsucht Zahlungen nach ihrer Beschreibung. 
- [x] Die Filteroptionen sollen erlauben, nur Ein- bzw. Auszahlungen (oder beide) anzuzeigen, 
- [x] und/oder nur Zahlungen einer bestimmten Person. 
- [x] Außerdem soll die Anzahl der angezeigten Einträge auf die letzten 15 oder 30 eingeschränkt werden können. 

- Auf einer separaten Seite sollen Statistiken zu den Zahlungen einsehbar sein, 
- Zunächst sollen es eine Übersichtsstatistik geben. 
- [x] Darin sollen Summe und Anzahl aller Ein- und Auszahlungen separat, 
- [x] sowie auch für alle Ein- und Auszahlungen gemeinsam (also quasi den aktuellen Kontostand) angezeigt werden. 
- [x] Zusätzlich sollen die fünf höchsten Ein- und Auszahlungen in einer Grafik dargestellt werden.
- [x] Die Ein- bzw. Auszahlungen sollen mit dem Namen der Person und der Beschreibung der Zahlung beschriftet sein.

- [x] Zur besseren Datenanalyse soll es auf der Statistikseite die Möglichkeit geben, einen Zeitraum bzw. eine Person auszuwählen. 
- [x] Zusätzlich zur Übersicht soll dann eine neue Statistik, die nur auf den Zeitraum und/oder die Person zutrifft, angezeigt werden. 
- [x] Die grafische Statistik wird ersetzt, soll sich dann also nur noch auf den angegebenen Zeitraum bzw. die angegebene Person beziehen.
